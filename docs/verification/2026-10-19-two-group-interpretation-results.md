# 2群比較の根拠受け渡し：実装・検証結果

## 実装

- v2バンドルで全特徴量・既存注釈・MassBank候補・スペクトルID対応を保持。
- 新しい6ツールを既存8ツールに追加。会話側LLMで解釈する構成。
- 根拠・背景・照合条件を版付きで保存し、再起動・ページ取得・同時更新を検証。
- RDFの空結果・失敗・未照会を分離。生物種に適合する背景がなければ経路検定を抑止。
- 既存注釈・低確度表記・手動訂正を保持し、生物学的背景でスペクトル順位を変更しない。

## 修正した問題

- DatasetStateにある解決済み注釈を、未解決のSME生候補と別の出典で保持。
- 不正なSPARQL JSON/bindingを空結果としてキャッシュせず、失敗として報告。
- 前処理の元総数・段階別除外・QC警告をバンドルへ保存。
- 分割照会後も既存のMassBankメタデータを保持。
- 大量の同一構造候補参照を特徴量内へ制限し、根拠を最大64件で追加取得。
- 特徴量ページは約128KiBを目安に件数を自動調整。小さなp/qを0へ丸めない。
- 大きな特徴量の後は通常ページ件数へ戻し、縮小した件数の永続継承を防ぐ。
- SQLite接続を明示的に閉じ、Windowsのファイルハンドルと版競合を検証。

## 検証の境界

実ms-data-parser MCP → 新export → 本体MCP → 照合 → 実PubChem → 根拠取得 → 解釈案まで確認した。
両極性の全特徴量・全根拠追加ページを実MCPで取得し、特徴量総数との一致、
微小なp値の保持、特徴量ページ128KiB未満、未照会候補なしを最終確認した。
科学的な結論は研究者レビュー前。LLMの主張に実在する根拠が付いていることと、
主張そのものの科学的妥当性は別である。
